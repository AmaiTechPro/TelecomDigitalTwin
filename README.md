# TelecomDigitalTwin

## Virtual Telecommunications and Cyber-Physical Systems Engineering Laboratory

An evolving browser-based telecommunications digital twin and virtual engineering laboratory.

### Current Capabilities

- Three.js-based 3D telecommunications site visualization.
- Python-based virtual telemetry generation.
- Simulated tower, backhaul, RAN and power monitoring.
- Deterministic fault-injection scenarios.
- MQTT messaging through Eclipse Mosquitto.
- Python MQTT integration using Paho MQTT.

### Technology Stack

- JavaScript
- Three.js
- Vite
- Python
- Eclipse Mosquitto
- Paho MQTT
- FastAPI (planned)
- WebSockets (planned)

### Simulation Disclaimer

All current sensor readings and fault scenarios are simulated. They do not represent measurements from physical telecommunications infrastructure.
